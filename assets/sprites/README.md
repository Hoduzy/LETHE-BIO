# 스프라이트 교체

이 폴더에 `<키>.png` 파일을 넣으면, 게임이 시작할 때 자동으로 그 그림을 씁니다.
파일이 없으면 `data/sprites.json` 에 정의된 임시 도형(사각형·원·다이아몬드)이 쓰입니다.
코드는 고칠 필요가 없습니다.

- 키 전체 목록과 임시 도형 크기: `data/sprites.json`
- 인물·소품의 기준점은 **발밑 가운데(아래 중앙)** 입니다. 크기가 임시 도형과 달라도 바닥에 맞춰 섭니다.
- 현재는 한 장짜리 그림(1프레임)을 씁니다. 애니메이션 시트는 이후 확장 예정.
- 배경(`bg_*`)은 왼쪽 위 기준으로 그 장면의 폭(`stage.width`) × 270 크기로 그리면 됩니다.
  배경 PNG가 있으면 장면 JSON의 `backdrop` 도형 대신 그 그림이 쓰입니다.
- 도트가 뭉개지지 않도록 원본 1배 크기(예: 도윤 12×24)로 그려 주세요.
